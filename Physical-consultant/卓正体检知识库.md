## 四、儿童体检套餐

> 单一套餐、无分档版本；以"体检项目 + 包含内容"的形式列示。

### 4.1 项目明细

| 类别 | 包含内容 |
|---|---|
| **健康信息采集** | 健康问卷、心理筛查（PSC）问卷 |
| **体格生长指标测量** | 身高、体重、体块指数（BMI） |
| **一般检查** | 生命体征（体温、心率、血压）；皮肤粘膜、浅表淋巴结；耳、鼻、咽部检查；心肺、胸廓及腹部检查；脊柱及四肢检查；发育情况评估（乳房、外生殖器等） |
| **听力筛查** | 声导抗测试（中耳功能检测） |
| **口腔检查** | 全口检查（龋齿、咬合、牙菌斑评估） |
| **超声及影像检查** | 腹部彩超（肝脏、胆囊、脾脏、胰腺、双肾） |
| **实验室检查** | 尿常规、血常规、随机血糖 |
| **体检报告解读** | 面诊或电话解读 |
| **眼视光检查** | 视力测试/视力筛查、电脑验光、非接触式眼压测量、裂隙灯检查、眼生物测量（测量眼轴）、色觉检查、斜视定性检查、立体视检查、眼底检查、眼底照相（单区块）、医学验光（含散瞳验光）、眼科医生面诊 |

### 4.2 儿童套餐特点与点评

**特点**
- **眼视光板块是最大亮点**：几乎覆盖儿童眼科全套——视力、验光、眼轴测量、斜视/立体视、散瞳验光，对近视防控和弱视/斜视早筛非常实用（尤其学龄儿童）。
- 含**心理筛查（PSC问卷）**，兼顾儿童情绪行为健康，是市面上儿童体检少有的心理维度。
- 含**发育情况评估**（乳房、外生殖器等），覆盖青春期发育判断。
- 听力（声导抗）、口腔（龋齿/咬合/牙菌斑）、脊柱四肢检查齐全，贴合儿童生长阶段常见问题。

**短板 / 注意**
- 未涉及儿童常见的内分泌专项（如生长激素、性激素、骨龄 X 光）——图中未见骨龄检测，长高/早发育深度评估需另加。
- 未标注年龄适用范围与价格，需以门店实际为准。
- 实验室项目较基础（血尿常规+随机血糖），如想查微量元素、维生素、过敏原需另行加项。

**适合人群**：建议配合学龄期近视防控、龋齿高发期、及生长发育监测的儿童定期体检；尤其**首次入园/入学体检、近视进展期儿童、疑似生长发育异常儿童**。

## 五、男女套餐横向对比

| 维度 | 女性套餐（上海） | 男性套餐（深圳） |
|---|---|---|
| 版本分档依据 | 按身体状况 | 按年龄（<40 / 40-50 / >50） |
| 起步会员价 | ¥1800 | ¥1700 |
| 最高档会员价 | ¥3100（不含妇科） | ¥3750 |
| 专属项目 | 乳腺彩超、子宫双附件彩超、CA125/CA153、妇科咨询查体、阴道分泌物+LCT+HPV（加购）、妇科医生解读、贫血三项 | 前列腺彩超、前列腺特异抗原三项、低剂量胸部CT、骨密度DEXA、人体成分分析、乙肝五项定量、康复体态评估 |
| 胸部检查 | DR胸片（全面版加脊柱DR） | 基础版DR胸片；标准/全面版升级为低剂量CT与DR胸片2选1 |
| 肿瘤标志物 | 4项（CA199/CEA/CA125/CA153） | 2项（CA199/CEA） |
| 妇科加购 | 有（+300 会员价） | 无 |
| 共同短板 | 均无无痛胃肠镜（男性版标注为付费加项，女性版未含） | 同左 |

**核心差异解读**
- 女性版更注重**乳腺+妇科+宫颈癌**体系，男性版更注重**前列腺+肺部（CT）+骨密度**体系，均贴合各自高发疾病谱。
- 男性版标准/全面档可用**低剂量胸部CT**（肺癌早筛金标准之一），女性版只有DR胸片——这是男性版在肺癌筛查上的优势。
- 女性版贫血三项、妇科三项为特色；男性版乙肝五项、人体成分、骨密度为特色。
