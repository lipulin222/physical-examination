# 体检报告解读 · 手机端 Demo

一个移动端风格的「体检报告智能解读」页面 Demo，白色高级简约风，模拟手机 App 的报告解读体验。

## 功能模块

- **01 健康总览**：报告概览 + AI 摘要解读
- **02 重点问题**：血脂超标 / 轻度脂肪肝 / 甲状腺结节
- **03 各系统健康状态**：人体示意图（SVG 绘制）+ 各系统卡片热区，点击查看系统详情与指标解读
- **04 健康趋势**：体重 / 腰围 / 总胆固醇 / 收缩压近 4 年趋势图表（带逐年数据标注）
- **05 生活方式管理**：饮食、运动、戒酒三方面行动建议
- **06 随访计划**：3 个月与 6–12 个月复查安排，可预约下次复查

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建）
- 内联 SVG 人体系统示意图 + CSS 网格布局
- 本地静态资源，无需后端

## 本地预览

任选一种方式启动静态服务后，用手机尺寸窗口打开 `index.html`：

```bash
# 方式一：Python
python -m http.server 8800

# 方式二：Node
npx serve .
```
